Misión: Mensaje Secreto

Criptografía, esteganografía y funciones hash para proteger la información digital.

Pregunta disparadora

¿Qué pasa realmente con un mensaje desde que lo enviamos hasta que llega a la otra persona?

Situaciones cotidianas

  • ¿Cómo hace WhatsApp para que solo la persona destinataria pueda leer un mensaje?
  • ¿Cómo sabe tu celular que una actualización no fue modificada antes de instalarla?
  • ¿Cómo envían información sensible los bancos o las tiendas cuando hacés una compra por Internet?

La misión

Enviar un mensaje secreto a otro equipo

  • Que no pueda ser leído si alguien lo intercepta.
  • Que no pueda ser descubierto aunque nadie lo lea.
  • Que se pueda comprobar que no fue modificado en el camino.

Etapa 1

🔐 Criptografía

¿Cómo hacemos para que nadie pueda leer nuestro mensaje si alguien lo intercepta?
¿Alcanza con ponerle una contraseña a un archivo?

Contraseña de archivo ≠ cifrado

  • Una contraseña controla quién puede abrir el archivo.
  • Cifrar transforma el contenido mismo, con una clave.
  • Cifrado simétrico: la misma clave sirve para cifrar y para descifrar (así funciona WhatsApp).
  • Herramientas del recurso: cifrado César (didáctico) y cifrado XOR.

Etapa 2

🖼️ Esteganografía

Si el mensaje ya está cifrado, ¿todos saben igual que estamos enviando algo secreto?
¿Qué pasaría si además de cifrarlo pudiéramos ocultar que existe?

Ocultar dentro de una imagen

  • Cada píxel se guarda como tres números: rojo, verde, azul (0 a 255).
  • Cambiar el último bit de cada número es invisible al ojo humano.
  • Ahí se puede "esconder" un mensaje, bit por bit.
  • No es solo digital: tinta invisible, micropuntos, mensajes ocultos en un texto.

Etapa 3

🧬 Funciones hash

Descargaste un mod para Minecraft. ¿Cómo sabés que nadie lo modificó para meterle un virus?

Una huella digital del contenido

  • Determinística: la misma entrada siempre da el mismo hash.
  • Unidireccional: no se puede "deshacer" para recuperar el original — no es cifrado.
  • Efecto avalancha: un solo carácter distinto cambia el hash por completo.
  • Ejemplo cotidiano: los sitios web guardan el hash de tu contraseña, no la contraseña misma.

Desafío final

Las tres técnicas juntas

  • Equipo A: cifra → oculta en una imagen → calcula el hash del mensaje original.
  • Equipo B: revela la imagen → descifra con la clave acordada → verifica el hash.
  • La clave se acuerda en persona, antes de empezar — nunca viaja junto al mensaje.
